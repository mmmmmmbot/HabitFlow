# HabitFlow 2.0
Native Android starter project.
Features implemented in this build:
- Unlimited habit list UI
- 50 habit colors palette (cycled automatically in the compact native build)
- Multiple habit icons
- Measurement choice: repetitions / days / time
- Dollar value per habit and reward on completion
- Per-habit streak
- Global daily streak and best streak
- 10 fire-color controls
- Statistics dashboard and habit chart-style summaries
- 10 Pixel skins priced $12–$2000 with purchase logic
- Glass-style rounded bottom navigation
- Animated splash and entrance animation
- Local SharedPreferences for core wallet/streak persistence

Build in Android Studio or another Android Gradle environment.
